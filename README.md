# 動画編集 案件管理 クローン

X の参照動画にあった「案件管理 & 請求書自動作成」アプリのローカル版です。

## 使い方

`index.html` をブラウザで開くだけで動きます。

- ステージ別の案件ボード
- 管理月ごとの案件表示
- 月次の売上・経費・粗利サマリー
- 新規案件の追加と編集
- ドラッグ&ドロップでステータス変更
- クライアント管理
- 発行元プロフィールの複数保存と選択
- 保存品目の追加・編集・削除
- 経費の追加・編集・削除
- 発行元と振込先の設定
- 納品済み案件から請求書を自動生成
- 値引率と源泉徴収の選択
- ブラウザの印刷機能で PDF 保存
- クライアント別の支払期限・値引・源泉徴収条件
- 共有スプレッドシートを元にした請求書フォーマット
- スズキ様用Excel雛形への自動差し込みとExcel出力
- 保存済み請求データから6月分の内容を一括読み込み
- PDF名を「2026年7月請求分_発行元名.pdf」形式で設定

## 登録済みテンプレート

- 株式会社キタコレ: 当月末払い、値引2%、源泉徴収あり
- スズキサトミ様（LeadInnovation管理分）: 当月20日払い、値引・源泉徴収なし
- 事務作業: 50円 / 件（スズキ様用）
- 事務作業A: 50円 / 件
- 事務作業B: 150円 / 件
- 動画編集・動画修正: 請求書作成時に単価を入力

## 2026年6月の保存済み請求データ

- キタコレ（事務作業）: 事務作業A 579件、事務作業B 133件、通信費 2,790円
- キタコレ（動画編集）: 動画編集 8,000円
- LeadInnovation: 事務作業 127件。スズキ様用Excel雛形を使用（宛名は会社名なしのスズキサトミ様、発行日 2026年7月1日）
- 今回の特例支払期限: 3件とも2026年7月20日

データはブラウザの localStorage に保存されます。
